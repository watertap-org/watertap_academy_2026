# WaterTAP Academy 2026

Welcome to the **WaterTAP Academy 2026** repository!

The WaterTAP Academy (WTA) is an 8-week course designed to introduce participants
to the **Water Treatment Technoeconomic Assessment Platform (WaterTAP)** and teach
them how to use it to analyze water treatment systems. While the Academy can be valuable
for participants with a range of coding and modeling experience, those with some prior
experience in process modeling, simulation, or Python programming will be best positioned
to get the most out of the course.

This repository contains the course materials for the **Fall 2026 WaterTAP Academy**,
including lecture materials, coding tutorials, and other
resources used throughout the course. For more information about downloading these materials locally, see the
[WaterTAP Academy Home Page](https://github.com/watertap-org/watertap_academy_2026/wiki)


## About WaterTAP

The Water treatment Technoeconomic Assessment Platform (WaterTAP) is a Python-based, open-source
library of water treatment models than can be used to assess water treatment trains through
simulation, optimization, and other advanced methods. WaterTAP supports the analysis of individual treatment
technologies as well as complete treatment trains, enabling users to investigate performance,
cost, energy consumption, and other system-level tradeoffs. WaterTAP development is funded by the National
Alliance for Water Innovation (NAWI), the U.S. Department of Energy’s Energy-Water Desalination Hub.

For more information, visit the [WaterTAP repository](https://github.com/watertap-org/watertap/tree/main) or the [WaterTAP documentation](https://watertap.readthedocs.io/en/latest/).


## Repository Contents

This repository has the following directories:

* **Week 1–8:** Contains the lecture materials, hands-on tutorials, and supporting files used during the corresponding lecture.
* **`src/`:** The source directory can be used to store any source code you may have.
* **`data/`:** The data directory can be used to store any data you may have.

To run the WaterTAP models and notebooks, consider the following options:
* **Quick Start:** Run them through Binder [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/watertap-org/watertap_academy_2026/main), an online service providing a short-lived temporary sandbox environment on public cloud resources where Jupyter notebooks can be run, free of charge, without having to install any software locally.
* **Installation** Install the necessary packages and dependencies. See the installation instructions [here](https://github.com/watertap-org/watertap_academy_2026/wiki)
